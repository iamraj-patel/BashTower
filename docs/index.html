Features
Everything you need to manage remote scripts

From ad-hoc script execution to scheduled jobs, BashTower covers the full lifecycle.

Multi-Host Execution

Run Bash or Python scripts on multiple hosts simultaneously via SSH with real-time output streaming.

Template Library

Save reusable script templates with syntax highlighting, categories, and dynamic argument support.

Dynamic Arguments

Parameterize templates with text, password, number, or select fields — filled at runtime.

Host Groups

Organize hosts into logical groups (e.g. "Web Servers", "Databases") for bulk targeted operations.

Secure SSH Key Storage

SSH private keys are encrypted at rest with AES-256 and never exposed in the UI.

Cron Job Scheduler

Schedule recurring script execution with standard cron expressions and a full execution history.

AI-Powered Troubleshooting

Analyze job failures and get fix suggestions via OpenAI, Google Gemini, or self-hosted Ollama.

Git Sync & Backup

Push templates to a Git repo for version control, and create full backups to a dedicated branch.

Red Hat Satellite Sync

Auto-import your host inventory directly from a Red Hat Satellite / Foreman instance.

Multi-User Auth

Built-in user management with admin roles. Authentication can be disabled for trusted environments.

Docker Ready

One-command deployment with Docker. Available on Docker Hub and GitHub Container Registry.

Responsive UI

Clean Tailwind CSS interface that works across desktop, tablet, and mobile browsers.

# docker-compose.yml
version: '3.8'
services:
  bashtower:
    image: ftsiadimos/bashtower   # or ghcr.io/ftsiadimos/bashtower:latest
    container_name: bashtower

      - "1008:1008"
    volumes:
      - ./instance:/app/instance
    restart: unless-stopped
docker compose up -d
# Clone the repository
git clone https://github.com/ftsiadimos/BashTower.git
cd BashTower

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the application
flask run --host=0.0.0.0 --port=1008

 Default login: admin / admin. You will be prompted to change the password on first login.

Usage Guide
From zero to running scripts in 5 steps
1

Add SSH Keys

Navigate to Keys and add your SSH private keys. They are encrypted with AES-256 at rest.

2

Add Hosts

Go to Hosts and register your servers with their hostname, SSH user, and port.

3

Organise into Groups

Use Host Groups to cluster servers logically (e.g. "Web", "DB") for bulk targeting.

4

Create Templates

Write Bash or Python scripts in Templates. Add dynamic {{arguments}} for flexibility.

5

Launch & Monitor

From the Dashboard, pick a template, select targets, and click Launch Script. Watch live output per host.

API Reference
RESTful API for automation

BashTower exposes a JSON API for scripting and integration.

MethodEndpointDescription
POST/api/auth/loginAuthenticate and get a session
GET/api/templatesList all script templates
POST/api/templatesCreate a new template
GET/api/hostsList all hosts
POST/api/hostsAdd a new host
GET/api/groupsList all host groups
POST/api/groupsCreate a host group
POST/api/runExecute a template on target hosts
GET/api/jobsList job history
GET/api/jobs/<id>Get job detail with per-host logs
GET/api/cronjobsList scheduled cron jobs
POST/api/cronjobsCreate a cron job

Example – Run a template

curl -X POST http://localhost:1008/api/run \
  -H "Content-Type: application/json" \
  -d '{
    "template_id": 1,
    "host_ids": [1, 2],
    "key_id": 1,
    "arguments": {"env": "production"}
  }'
